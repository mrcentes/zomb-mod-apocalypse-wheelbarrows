[h1]Apocalypse Wheelbarrows[/h1]

A focused Build 42.20 maintenance and enhancement pass for Wheelbarrow from Hydrocraft v2. This mod keeps the spirit of the original wheelbarrow mod intact while making it usable and stable in current Build 42 play.

Both wheelbarrow leverage and the skill levels required to craft each wheelbarrow tier are configurable in sandbox settings on a single mod settings page.

[h2]What This Mod Does[/h2]

[list]
[*]Fixes the equipped-drop crash path in Build 42
[*]Adds three wheelbarrow variants: Wooden, Reinforced, and Metal
[*]Adds per-variant leverage settings for both single-player and multiplayer servers
[*]Adds Build 42 JSON localization support
[*]Keeps the wheelbarrow useful without fighting the current Build 42 container cap behavior
[/list]

[h2]Why Leverage Instead Of Huge Capacity[/h2]

Build 42 appears to clamp bag-style containers in ways that make old high-capacity wheelbarrow behavior unreliable. In testing, the container could briefly display a higher value, then still behave like it had a much lower effective limit.

Instead of pretending that cap is gone, this mod takes a more reliable approach:

[list]
[*]The wheelbarrow remains a normal container
[*]Items inside it have their live weight reduced
[*]When items leave the wheelbarrow, their original weight is restored
[*]Each wheelbarrow type has its own configurable leverage value
[/list]

The result is a wheelbarrow that still feels powerful and practical, but behaves consistently in Build 42.

[h2]Wheelbarrow Types[/h2]

[list]
[*][b]Wooden Wheelbarrow[/b] - baseline version
[*][b]Reinforced Wheelbarrow[/b] - stronger mid-tier version
[*][b]Metal Wheelbarrow[/b] - strongest version
[/list]

[h2]Settings[/h2]

[b]In the sandbox UI, this mod uses one settings page.[/b]

Build 42 custom sandbox options do not expose the same section-header support the hardcoded vanilla tabs use, so these options are grouped by name and kept in fixed order by wheelbarrow type.

[b]Wooden Wheelbarrow:[/b]
[list]
[*]Leverage default: 4x
[*]Recipe skill default: Woodwork 2
[/list]

[b]Reinforced Wheelbarrow:[/b]
[list]
[*]Leverage default: 6x
[*]Recipe skill defaults: Woodwork 4, Mechanics 2
[/list]

[b]Metal Wheelbarrow:[/b]
[list]
[*]Leverage default: 8x
[*]Recipe skill defaults: Mechanics 4, Metal Welding 4
[/list]

Higher leverage values mean more mechanical advantage.

Setting any one of those required skill values to 0 (zero) removes that specific requirement.

[b]Single Player:[/b]
Set leverage and recipe skill requirements in the sandbox settings for your save before loading it.

[b]Multiplayer:[/b]
Set leverage and recipe skill requirements in the server sandbox settings. The server values are authoritative for multiplayer.
